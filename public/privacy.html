Privacy Policy

Last updated: September 1, 2026

Coach is a personal, single-user training and nutrition assistant operated by its sole user. It is not a commercial product, has no customer accounts, and does not serve the public. This policy describes what data the application handles and how, including its use of Google user data.

What the application does

Coach reads workout history from Hevy, plans training and nutrition, and communicates with its one user by email. It integrates with Google Calendar to place planned training sessions on the user's calendar and to read the day's agenda when composing briefings.

Google user data

The application requests two Google OAuth scopes:

  • calendar.events — used to create, update, and delete calendar events that the application itself created (training sessions). Events are tagged with a private extended property, and the application only modifies or deletes events carrying that tag. It never alters events created by anything else.
  • calendar.readonly — used to list the user's calendars and read upcoming events so that daily briefings reflect the real schedule.

Calendar data is read at the moment a briefing or scheduling job runs and is used only to compose that output. Event titles and times from the user's calendar may be included in emails sent to the user and may be passed to an AI model (Anthropic's API) solely to compose those emails. Calendar data is not used for advertising, is not sold, and is not shared with any third party beyond the service providers listed below, and never for their own purposes.

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Other data

The application stores the user's own training, nutrition, and health log in a private database (Turso). Inbound email from the user is archived so it can be processed reliably. All of this data belongs to and describes the one user who operates the application.

Service providers

The application runs on Vercel (hosting), stores data in Turso (database), sends and receives email via Resend, and composes text via the Anthropic API. Data passes through these providers only as needed to operate the application.

Retention and deletion

The Google OAuth refresh token is stored in the application's private configuration. Access can be revoked at any time at myaccount.google.com/permissions, which immediately ends the application's ability to read or write calendar data. To request deletion of any stored data, contact the operator at the address below.
